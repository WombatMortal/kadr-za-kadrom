# Киноклуб «Кадр за кадром»

Интерактивный сайт частного онлайн-киноклуба: афиша недели, голосование, правила, участники, кинохроника, заявка на вступление и демонстрационный личный кабинет с оценками.

## Запуск

```bash
pnpm install
pnpm run dev
```

Сборка:

```bash
pnpm run build
```

## Важно

- Анкета на вступление работает как интерфейсный прототип.
- Вход в личный кабинет демонстрационный: пароль не отправляется и не сохраняется.
- Оценки участников помечены как демоданные.
- Для рабочей версии потребуется серверная часть, база данных и подтверждение входа через Telegram.

## Публикация

GitHub Actions собирает проект и публикует содержимое `dist/client` через GitHub Pages.
